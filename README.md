# 「圖片自動調整尺寸並填充工具」

功能介紹：
這個程式的主要功能是將一個指定資料夾中的圖片自動調整尺寸並填充，以便它們符合特定的目標尺寸，通常用於在社交媒體平台（如Instagram）上分享圖片。具體功能包括：

圖片調整：根據指定的目標尺寸，將圖片進行等比例縮放，保持原始圖片的寬高比。
圖片填充：將調整大小後的圖片粘貼到一個新的空白圖像上，以便它們符合目標尺寸，同時在四周添加白色填充區域。
操作流程：

運行程式後，它會要求輸入包含要調整尺寸的圖片的資料夾路徑。
程式會自動創建一個名為「resize_for_IG」的資料夾，用於存儲處理後的圖片。
程式將遍歷指定資料夾中的所有文件，確認它們是圖片文件（以.png、.jpg、.jpeg或.gif結尾）。
對每個符合條件的圖片，程式會自動調整其大小並填充，然後將處理後的圖片保存到「resize_for_IG」資料夾中，保持原始文件名。
當所有圖片處理完畢後，程式會顯示「處理完成」的消息，等待用戶關閉窗口。
這個程式對於需要將多個圖片快速調整尺寸以適應特定尺寸要求的用戶來說非常實用，特別適合需要在社交媒體平台上共享圖片的情況。
