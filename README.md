# IG_Photo_Editer

**版本：2.4**

## 專案簡介

`IG_Photo_Editer` 是一個用於處理Instagram圖片的工具，提供添加浮水印和白邊的功能。透過圖形用戶界面（GUI），用戶可以輕鬆選取圖片資料夾，並選擇處理選項來進行批量圖片處理。

## 功能介紹

- **浮水印添加**：自動在圖片指定位置添加自定義浮水印。
- **白邊添加**：為圖片添加白色邊框，使圖片符合Instagram的尺寸要求。
- **批次處理**：支援批次處理多張圖片，並可選擇一般模式或進階模式。
- **日誌記錄**：處理過程中的所有操作會記錄在日誌中，方便查看處理過程和結果。

## 模式說明

### 一般模式

- **處理範圍**：僅針對選定資料夾中的圖片進行處理，不會遞迴進入子資料夾。
- **使用場景**：適合處理單一資料夾內的圖片，快速完成浮水印或白邊添加。

### 進階模式

- **處理範圍**：遞迴處理選定資料夾及其所有子資料夾中的圖片，並保持原有資料夾結構。
- **使用場景**：適合需要處理大量圖片且分佈於多個子資料夾的情況，適合更複雜的批次處理需求。

## 使用方法

1. **下載與安裝**
   - 下載並解壓縮此專案的執行檔（EXE）。

2. **啟動工具**
   - 執行已解壓縮的 `.exe` 檔案來啟動工具。

3. **選擇資料夾**
   - 點擊 "Select Image Folder" 按鈕，選擇需要處理的圖片資料夾。

4. **選擇處理模式**
   - 在左側面板中選擇 "General Mode" (單一資料夾處裡) 或 "Advanced Batch Mode" (含有子資料夾的處裡)。
   - 根據需求選擇 "Add Watermark" 或 "Add White Border" 選項。

5. **選擇浮水印**
   - 如果選擇了 "Add Watermark"，請點擊 "Select Watermark" 按鈕並選擇浮水印圖片。

6. **開始處理**
   - 點擊 "Start Processing" 開始批次處理圖片。處理完成後，結果將顯示在指定的輸出資料夾中。

## 注意事項

- 確保所有圖片格式支援：`png`, `jpg`, `jpeg` , `heif`, `heic`。
- 處理結果將儲存在選擇的圖片資料夾內新建的 `IG_LOGO_Cropper` 資料夾中。
