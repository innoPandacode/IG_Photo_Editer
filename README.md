# 「圖片水印與加白邊工具」

功能介紹：
這個程式的主要功能是對一個指定的圖片資料夾中的圖片進行水印處理和加上白邊效果，用於製作社交媒體（如Instagram）上的圖片。具體功能包括：

水印添加：從一個指定的標誌（LOGOPATH）資料夾中選擇一個 LOGO 圖片，將其添加到所有圖片上，並可以自動調整大小和位置。
圖片白邊：將圖片自動調整大小，使其符合 2048x2048 像素的尺寸，然後在四周添加白色邊框。
環境設定：在運行程式之前，可以設定標誌資料夾的位置和圖片資料夾的位置。

操作流程：
運行程式後，首先需要設定標誌（LOGO）資料夾的位置。如果該資料夾不存在，程式會自動創建它。
然後，程式會要求輸入圖片資料夾的路徑。如果指定的資料夾不存在或其中沒有圖片文件，程式會顯示錯誤消息並退出。
程式會列出圖片資料夾中的圖片數量，然後等待一秒後繼續。
程式會自動創建一個輸出資料夾，用於存儲處理後的圖片。
接下來，您需要從標誌資料夾中選擇一個 LOGO 圖片，程式將自動將該 LOGO 添加到所有圖片上。您可以根據需要調整 LOGO 的大小和位置。
程式將詢問是否要為處理後的圖片添加白色邊框。您可以選擇是或否。
最後，程式將完成處理，並等待按 Enter 鍵退出。
這個程式對於需要將 LOGO 添加到一系列圖片並將它們調整為特定尺寸以在社交媒體上共享的用戶來說，非常有用。
